Device test steps

  1. Put up to 3 devices side by side on a desk at the back of a room. Type each device's name above.
  2. Turn off operating-system processing first (list below).
  3. Pass 1: choose "processing OFF" on every device and start all of them. Stay quiet for 10 s. Clap 4 times from the front of the room, about 3 s apart. Wait. Read aloud when the page says so. Each page stops at 45 s.
  4. Pass 2: choose "processing ON" and repeat the same claps.
  5. Download every WAV and its info file. Measure the room: length, width and height.
  6. Put all files in private/device-test/. Do not commit them.

Turn off operating-system processing

  • Windows 11: Settings → System → Sound → your microphone → turn off "Audio enhancements" and, if shown, "Voice clarity".
  • Mac, iPhone, iPad: while recording, open Control Center → Mic Mode → Standard.
  • Chromebook: Settings → Device → Audio → turn off noise cancellation.
  • Android: no system switch. The browser flags are all we control.

The page can only read the browser's flags. Processing inside the operating system is invisible here; the WAV analysis looks for its signature.
